# PLC & Automation Engineering Portfolio

This repository documents my transition from software development into
PLC programming, industrial automation and, eventually, OT cybersecurity.

I am a software developer with experience primarily in backend development,
APIs, cloud infrastructure and automation. I am using this portfolio to
develop practical skills in PLC programming, industrial control systems and
industrial networking.

The projects in this repository are developed using CODESYS and Factory I/O,
with the goal of progressively building more complex automation systems.

## Portfolio

| Project | Description | Technologies | Status |
|---------|-------------|--------------|--------|
| [Mini Conveyor](./miniConveyor) | Basic conveyor control | CODESYS, Factory I/O | Complete |
| [Mini Conveyor Timer & Alarm](./miniConveyorTimerAndAlarm) | Conveyor with timer and alarm logic | CODESYS, Factory I/O | Complete |

More projects will be added as my skills develop.

## Software Requirements

Projects in this repository may require:

- CODESYS Development System
- CODESYS Control Win (for local runtime/simulation)
- Factory I/O

Specific software versions and requirements are documented in each
project's README.
