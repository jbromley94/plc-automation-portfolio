## Software Requirements

Projects in this repository may require:

- CODESYS Development System
- CODESYS Control Win (for local runtime/simulation)
- Factory I/O

Specific software versions and requirements are documented in each
project's README.

### Quick Start

These projects are fully downloadable and can be run locally using CODESYS and Factory I/O. No physical PLC hardware is required.

1. Install CODESYS Development System V3
2. Install CODESYS Control Win, but this should be built in the base download depending on your installation
3. Install Factory I/O
4. Clone or download this repository or each singular project if desired
5. Open a project folder and follow its README

## How to Use This Repository

These projects are intended to be downloaded or cloned and opened locally.

### Option 1: Clone with Git

```bash
git clone https://github.com/jbromley94/plc-automation-portfolio.git
cd plc-automation-portfolio
```

### Option 2: Download as ZIP

Click:

`Code` → `Download ZIP`

Extract the repository and open the individual project directory.
