# 13-UPCOMING-multiLevelDistributionAndPalletisingSystem

## Overview

Project 13 is an upcoming industrial automation portfolio project based around a **multi-level distribution and palletising system** built in Factory I/O.

The project is currently in the **initial/placeholder stage** and will be developed further using:

- **Factory I/O** – plant simulation
- **CODESYS** – PLC control logic
- **CODESYS HTML5 / WebVisu** – machine-level HMI and custom web controls
